## Who I am

I build projects to learn by doing—especially at the intersection of **AI workflows** and **usable interfaces**. My public work shows hands-on exploration of:
- Agentic retrieval workflows over documents (NASA Artemis RAG assistant)
- Full-stack and role-based web applications (patients, doctors, pharmacists)
- Front-end product builds (portfolio, generators, calculators, landing pages)
- Developer tooling practice with GitHub, Copilot, and Codespaces

## Skills & Technologies

- **AI & Data Apps:** Python, Jupyter Notebook, LangChain, LangGraph, RAG/agentic workflows, vector database concepts, Streamlit, verification-oriented document QA
- **Web Development:** JavaScript, Node.js, Express, SQLite, HTML, CSS, responsive UI, dynamic pages, web application development
- **Product Features:** user-role workflows, data export, lap-time/user tracking, document/research-based applications
- **Workflow & Tools:** Git, GitHub, GitHub Copilot, GitHub Codespaces

## What I’m striving for
